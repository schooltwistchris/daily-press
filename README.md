# Daily Press

A framework for AI-generated hyperlocal daily newspapers.

This is the marketing site for Daily Press, a concept for letting hyperlocal publishers spin up their own AI-written daily edition — design a masthead, pick the beats, and deploy a self-publishing newspaper.

## Status

Marketing site live at [local-press-power.lovable.app](https://local-press-power.lovable.app).

The working prototype that proves the underlying pattern is the **Medford Mercury** — an AI-written daily newspaper for Medford, MA that publishes every morning via GitHub Actions calling the Anthropic API, deployed to Cloudflare Pages.

- Live publication: [medford-mercury.pages.dev](https://medford-mercury.pages.dev)
- Source: [github.com/schooltwistchris/medford-mercury](https://github.com/schooltwistchris/medford-mercury)

## Stack

- React + Vite + Tailwind
- Built on [Lovable](https://lovable.dev)
- Connected to this repo for version control
